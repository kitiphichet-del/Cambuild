# Cambuild — LumaCam

Android camera enhancement app (Kotlin + CameraX). This repository is being initialized with the LumaCam source, photo processing modes and a GitHub Actions APK build workflow.

## Features

- Capture front/back camera and import from gallery
- Auto / Natural / Night / Portrait photo enhancements
- Before/after preview and original/enhanced photo saving
- Offline image processing fallback

> Development build: image-quality improvement is device-dependent, and AI-based enhancements only work on supported hardware.
