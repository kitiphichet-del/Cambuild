# Cambuild — LumaCam (ต้นแบบ Android v0.1)

แอปกล้อง Android ที่ช่วยปรับภาพหลังถ่ายให้สวยขึ้น โดยไม่ส่งรูปภาพไปยังเซิร์ฟเวอร์ภายนอก

## ฟังก์ชัน

- ถ่ายภาพจากกล้องหน้าและหลัง ด้วย CameraX
- เลือกรูปจากแกลเลอรี
- โหมด Auto / Natural / Night / Portrait
- โหมด Portrait ตรวจจับใบหน้าด้วยโมเดล ML Kit ที่ทำงานบนเครื่อง เพื่อช่วยปรับแสงบริเวณใบหน้า
- ปรับแสง คอนทราสต์ สี และความคมชัดแบบประมวลผลบนเครื่อง
- เปรียบเทียบภาพต้นฉบับกับภาพที่ปรับแล้ว
- บันทึก 2 ไฟล์ JPG ไปที่ Pictures/LumaCam

**ข้อจำกัด:** โหมด Auto, Natural และ Night เป็นการปรับภาพด้วยอัลกอริทึม ไม่ใช่ AI สร้างรายละเอียดใหม่ ไม่สามารถชดเชยข้อจำกัดของเซนเซอร์โทรศัพท์ได้ทั้งหมด และยังไม่มี HDR หลายเฟรม, RAW, depth bokeh หรือ Neural super-resolution

## วิธีรับไฟล์ APK จาก GitHub

1. เปิดหน้า [GitHub Actions](https://github.com/kitiphichet-del/Cambuild/actions/workflows/android-apk.yml)
2. เลือก **Build Android APK** และเลือกการรันล่าสุด หรือกด **Run workflow** แล้วเลือกสาขา **main**
3. ตรวจสถานะให้เป็นเครื่องหมายถูกสีเขียว **Success** ก่อน
4. เข้าไปที่การรันนั้น เลื่อนลงไปที่ **Artifacts** และกด **Cambuild-LumaCam-debug-APK**
5. ได้ไฟล์ ZIP ให้แตก ZIP ก่อน แล้วนำ **app-debug.apk** ไปติดตั้งในมือถือ Android 10 ขึ้นไป
6. เมื่อ Android ขออนุญาตกล้อง ให้กดอนุญาตเพื่อถ่ายภาพ

หากสถานะเป็น Failed ให้เปิดขั้นตอน **Build debug APK** แล้วนำข้อความ error ส่งกลับมาเพื่อแก้ซอร์สโค้ด

## สถานะการทดสอบ

คอมมิตโค้ดขึ้น GitHub แล้ว แต่ยังไม่ได้ยืนยันว่า GitHub Actions คอมไพล์สำเร็จหรือทดสอบบนอุปกรณ์จริง จึงยังไม่เรียกว่า APK พร้อมติดตั้งจนกว่าจะเห็นสถานะ Success
